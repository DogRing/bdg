# SPEC — `engine/agent` · Core

> Scope: Agent struct, Config, 8-phase Tick skeleton, phase 1–4/7 logic, §F threat wiring, referent urgency, replan/execute/ApplyOutcome scaffolding
> Status: P7 · Leaf level: L5 · Owner agent: implementer
> Source: split from `engine/agent/SPEC.md` (monolith)

## 1. Purpose

Drives one agent through one tick of the decision loop (design §1.1):
`perception → value appraisal → goal mediation → planning (HTN+GOAP) → durative execution →
signal → belief/reputation/reliance update`. It is the **orchestrator** (D5): it owns the agent's
dynamic `Body` state and `ToM`, sequences the upstream pure modules, and emits **intents** — it
never mutates the world directly and never decides *what is wanted* (`values`/`needs`) or *how to
get it* (`planner`).

This **core** file owns the foundational structure every other domain SPEC builds on: the `Agent`
struct, the single shared `Config` type, the `Services`/`WorldView`/`FunctionSpec`/`Intent`/`Signal`
contracts, the `New` constructor, the 8-phase `Tick` skeleton, the per-tick logic for phases 1–4
and the trade slice of phase 7, the §F threat-perception → Safety-intensity wiring, the
referent-aware Urgency aggregation (`combinedPriority`), and the `replan`/`execute`/`ApplyOutcome`
scaffolding. It additionally owns the live Body scalars (Stamina, Mood, Adrenaline, Urgency) it
feeds into the gate/planner snapshot each tick so the P3 gates (`stamina`, `apathy`,
`conscience`-relief, `adrenaline`-cost) can read them (`engine/gates/SPEC.md`).

Three sibling domain SPECs own the slices this file delegates:
- **`SPEC-dynamics.md`** — Stamina drain/regen (§D), Adrenaline surge/crash (§E), Mood update,
  Resentment drift / Aggression-Drift threshold (§B/§B-drift), the per-call planner budget formula
  (§A-budget).
- **`SPEC-coping.md`** — the coping cascade (rebind → longing → latent → apathy, §A), the per-stat
  β self-calibration, and Resentment accrual (§B/§C).
- **`SPEC-politics.md`** — emergent reliance (§G), Vote delegation (§H), Influence-weighted gossip
  (§I), `FunctionSpec` semantics, `functionForGoal`, `handleRelianceTrigger`, `emitVoteIfEligible`,
  `processIncomingSignals`/`processVoteSignal`/`processGossipSignal`, `bestRelyOnFor`, `allBeliefs`.

All rate constants are injected from `content/balance.yaml` (D10); the package hardcodes none.

## 2. Agent struct (Body fields, ToM, Config, deliberation state)

Verbatim from `agent.go` / the monolith Public Interface:

```go
// Agent is one simulated villager: its dynamic Body state, its ToM (incl. ToM[self],
// D8), its current Goal and durative Plan, and its coping state. Owned and mutated
// ONLY through this package's methods (Tick reads + assembles intents; ApplyOutcome
// folds back the resolved outcome). The world holds the Agent and calls these in the
// fixed apply order (D12).
type Agent struct {
    ID  core.AgentID
    Pos core.Vec2

    // Body — the dynamic state (glossary State layers).
    Inventory       map[core.Tag]int           // item-kind id count (sorted-key iteration only, D12)
    Stamina         float64                    // consumable effort budget, in [0, StaminaMax]   → drained/regenerated by SPEC-dynamics.md §D
    Mood            float64                    // signed; += lambda*(actual-expected), decays to baseline → SPEC-dynamics.md §E
    Adrenaline      float64                    // urgency-driven surge in [0, AdrMax]             → SPEC-dynamics.md §E
    NeedIntensities map[core.Dimension]float64 // grown need intensity per Dimension (higher = worse); incl. the conditional Safety intensity driven in §F

    // Real Stats — the god view; decides OUTCOMES only (engine/world), NEVER read by decisions (D8).
    RealStats stats.Stats

    // ToM — the agent's whole theory-of-mind, INCLUDING ToM[self]; decisions read ToM[self] (D8).
    ToM tom.ToM

    // Values — the agent's held value directions (Dimension + Referent + Posture + Setpoint).
    // What the agent ultimately cares about. Grows as the agent discovers new referents.
    // Populated at construction; read by appraisePlace (Place) / appraiseCollective (Collective).
    Values []core.Value // P5: value directions beyond Self-needs (Place/Collective referents)

    // Cfg — immutable per-agent config (injected at construction from balance.yaml, D10).
    Cfg Config

    // Deliberation state across ticks.
    Goal    core.Dimension   // the currently-pursued goal Dimension (empty = none raised)
    Plan    planner.Plan     // the active durative plan (ordered ActionIDs being executed)
    PlanIdx int              // index of the action currently executing within Plan.Actions
    Elapsed core.GameMinutes // game-minutes the current action has been running (durative progress)

    Coping     CopingState  // where the agent sits in the coping cascade (design §3) → SPEC-coping.md §A
    FailStreak int          // P3: consecutive failed re-plans; resets on any plan/action success → SPEC-coping.md §A
    Latent     []LatentGoal // unmet goals stored below the surface (Longing/Latent), feed Resentment → SPEC-coping.md / SPEC-dynamics.md §B
    Resentment float64      // P3: accrues while Latent on trigger events; drives Aggression/Affinity drift (D2) → SPEC-dynamics.md §B
}
```

`CopingState` and `LatentGoal` (from `types.go`):

```go
type CopingState uint8
const (
    Idle      CopingState = iota // pursuing a goal with a valid plan (or no goal raised)
    Rebinding                    // no plan found: expand budget / substitute goal
    Longing                      // unmet goal stored in latent memory
    Latent                       // goal persists below the surface; feeds Resentment drift
    Apathy                       // gave up: goal suppressed, Mood decays toward baseline
)

// LatentGoal is an unmet goal pushed below the conscious threshold (Longing/Latent).
type LatentGoal struct {
    Dim       core.Dimension
    Since     core.Tick
    Intensity float64 // residual urgency carried below the surface
}
```

## 7. The 8-phase Tick loop — SKELETON

`func (a *Agent) Tick(world WorldView, now core.Tick, rng *rng.RNG, svc Services, emit core.EventEmitter) []Intent`
is READ-ONLY w.r.t. the shared world snapshot (D12 read→plan→collect→apply); it mutates only the
receiver's own Body/coping/plan state.

```
Phase 0:  process incoming signals (gossip Influence-weighted + Vote)  → SPEC-politics.md §processIncomingSignals
Phase 1:  perceive (sight/smell/hearing)                               → this file §7.1
Phase 1b: threat scan + Safety-intensity drive + GoalSelected emit     → this file §F (P6 Blocker Group A)
Phase 2:  decay needs                                                  → this file §7.2
Phase 3:  appraise (self + other + place + collective) → combinedPriority → this file §7.3 / §9
Phase 4:  mediate goal                                                 → this file §7.4
Phase 4b: collective-defensive + per-threat defensive overrides        → this file §F + §9 (BLOCKER-2)
Phase 5:  plan (replan + budget) → on err: coping cascade + reliance    → this file §10 (replan); SPEC-coping.md §A (cascade); SPEC-dynamics.md §A-budget; SPEC-politics.md §G (reliance)
Phase 6:  execute (stamina drain/regen)                                → this file §11 (intent build); SPEC-dynamics.md §D (stamina logic)
Phase 7:  signal — trade (Offer/Accept/Reject) + Vote                  → this file §12 (trade); SPEC-politics.md §H (Vote)
Phase 8:  dynamics (adrenaline/mood/resentment + Aggression-drift)      → SPEC-dynamics.md §E/§B-drift; SPEC-coping.md §B (accrueResentment)
```

The actual loop body (verbatim ordering from `tick.go`):

```go
func (a *Agent) Tick(world WorldView, now core.Tick, rng *rng.RNG, svc Services, emit core.EventEmitter) []Intent {
    var intents []Intent

    // Phase 0 (P6): fold vote/hearsay from other agents — SPEC-politics.md
    a.processIncomingSignals(world)

    // Phase 1: perceive
    seen := svc.Sensor.Sight(a.Pos, world)
    _ = svc.Sensor.Smell(a.Pos, world)
    _ = svc.Sensor.Hearing(a.Pos, world.SoundEvents())

    // Phase 1b (§F, P6 Blocker Group A): threat scan + Safety-intensity drive (BEFORE phase-3 appraise)
    threats := a.scanThreats(seen)
    a.driveConditionalSafety(threats, svc.Needs)

    // §F defensive-goal reflex: precompute goalForced; emit GoalSelected immediately;
    // the actual a.Goal override is applied in phase 4b (after mediateGoal) so it truly overrides.
    goalForced := len(threats) > 0 && a.Cfg.SafetyDim != ""
    if goalForced {
        a.Plan = planner.Plan{} // clear plan so needsReplan returns true
        emit.Emit(core.Event{ /* GoalSelected{dimension: SafetyDim, priority:1.0, eff_value:1.0} */ })
    }

    // Phase 2: decay needs
    a.decayNeeds(svc.Needs)

    // Phase 3: appraise (self) + referent appraisals → combinedPriority (§9)
    priorities    := a.appraise(svc.Needs, svc.Values)
    maxOther      := a.appraiseOthers(world, svc.Needs, svc.Values, svc.Stats)
    maxPlace      := a.appraisePlace(world, svc.Needs, svc.Values)
    maxCollective := a.appraiseCollective(world, svc.Needs, svc.Values)
    selfMax       := float64(priorities[0].Priority)
    combinedPriority := max(selfMax, maxOther, maxPlace, maxCollective)   // OWNED here; consumed by SPEC-politics §H

    // Phase 4: mediate goal
    goalChanged := a.mediateGoal(priorities)

    // Phase 4b: collective-safety defensive override (BLOCKER-2)
    if defDim, fire := a.defensiveCollectiveGoal(world, svc.Needs); fire && a.Goal != defDim {
        a.Goal = defDim; goalChanged = true
    }
    // Phase 4b: per-threat defensive override (§F BLOCKER-1)
    if goalForced && a.Goal != a.Cfg.SafetyDim {
        a.Goal = a.Cfg.SafetyDim; goalChanged = true
    }

    // Phase 5: plan
    if a.needsReplan(goalChanged) {
        plan, trace, err := a.replan(world, now, rng, svc, priorities, combinedPriority)
        if err != nil {
            a.enterCopingCascade(err, now, priorities, svc.Stats, emit)        // SPEC-coping.md §A
            a.handleRelianceTrigger(world, 0, err, emit)                       // SPEC-politics.md §G
        } else {
            a.Plan = plan; a.PlanIdx = 0; a.Elapsed = 0; a.Coping = Idle; a.FailStreak = 0
            emitGoalSelected(emit, now, a.ID, trace); emitPlanBuilt(emit, now, a.ID, trace)
            a.handleRelianceTrigger(world, trace.TotalCost, nil, emit)         // SPEC-politics.md §G
        }
    }

    // Phase 6: execute (emit current durative-step intent; stamina via SPEC-dynamics §D)
    if intent := a.execute(now, svc.Actions, world); intent.Kind != IntentNone {
        intents = append(intents, intent)
    }

    // Phase 7: signal — trade (this file §12) + Vote (SPEC-politics §H)
    if sigIntent := a.emitSignal(now, world); sigIntent.Kind != IntentNone {
        intents = append(intents, sigIntent)
    }
    if voteIntent := a.emitVoteIfEligible(now, world, combinedPriority); voteIntent.Kind != IntentNone {
        intents = append(intents, voteIntent)
    }

    // Phase 8: dynamics — SPEC-dynamics.md §E (adrenaline/mood) + §B-drift (updateResentment, every tick)
    a.updateDynamics(priorities) // NOTE: SELF-ONLY urgency (priorities), NOT combinedPriority

    // Phase 8 (accrual): SPEC-coping.md §B accrueResentment (Latent-gated, trigger-gated)
    triggers := world.ResentmentTriggers(a.ID)
    a.accrueResentment(triggers, svc.Stats, emit)

    return intents
}
```

> **Ordering nuance (latest code wins):** the §F forced-Safety goal is *announced* in phase 1b
> (`GoalSelected` emitted, plan cleared) but the actual `a.Goal = SafetyDim` assignment is applied in
> **phase 4b**, AFTER `mediateGoal`, so it truly overrides the mediated goal rather than being
> re-mediated away. Phase 8's `updateDynamics` deliberately uses self-only `priorities`, not
> `combinedPriority` — the physiological adrenaline surge responds only to the agent's own deficit.

### 7.1 Phase 1 — perceive

The agent senses the world for the trace; the percepts are read-only:

```go
seen := svc.Sensor.Sight(a.Pos, world)              // []perception.PerceivedEntity (Tags copied)
_ = svc.Sensor.Smell(a.Pos, world)                  // smell percepts (reserved)
_ = svc.Sensor.Hearing(a.Pos, world.SoundEvents())  // sound percepts (reserved)
```

`seen` is consumed by the §F threat scan (§F). No state is mutated in phase 1 proper.

### 7.2 Phase 2 — decay needs

Grows the consumable need intensities by their per-minute rate (D9: objects carry only supply; the
need grows on its own). Conditional needs (e.g. Safety, `Rate==0`) are NOT grown here — they are
driven by §F.

```go
func (a *Agent) decayNeeds(needsReg *needs.Registry) {
    tickMinutes := core.GameMinutes(1)
    for _, dim := range needsReg.Kinds(needs.Consumable) {     // sorted-key iteration (D12)
        def, ok := needsReg.Def(dim); if !ok { continue }
        a.NeedIntensities[dim] += def.Rate * float64(tickMinutes)
    }
}
```

### 7.3 Phase 3 — appraise (self)

Computes the Priority-ordered Dimension list for goal mediation, over `needsReg.IDs()` (which
includes the conditional Safety dimension whose intensity §F just drove):

```go
func (a *Agent) appraise(needsReg *needs.Registry, valsCfg *values.Config) []planner.DimensionPriority {
    for _, dim := range needsReg.IDs() {                       // sorted (D12)
        def, ok := needsReg.Def(dim); if !ok { continue }
        intensity := a.NeedIntensities[dim]                    // §F-driven Safety intensity is read here
        standing  := values.ComputeStanding(def, intensity)
        salience  := values.ComputeSalience(standing)
        weight    := valsCfg.Weight(dim)
        priority  := values.ComputePriority(salience, weight)
        result = append(result, planner.DimensionPriority{Dim: dim, Priority: priority, Salience: salience})
    }
    // sort by Priority desc; ties broken by Dimension string asc (D12)
    return result
}
```

The Self-Priority terms feed both `selfMax` (the urgency proxy) and `mediateGoal`. The referent
appraisals (`appraiseOthers`/`appraisePlace`/`appraiseCollective`) are in §9.

### 7.4 Phase 4 — mediate goal (Stickiness / GoalDeadband anti-thrash)

Owned here (per planner OQ). Applies stickiness to the current goal's Priority and only switches when
a rival beats the (sticky) current by more than `GoalDeadband`:

```go
func (a *Agent) mediateGoal(priorities []planner.DimensionPriority) bool {
    if len(priorities) == 0 { if a.Goal != "" { a.clearGoal(); return true }; return false }
    prioMap := /* Dim → Priority */
    currentPrio := values.Priority(0)
    if a.Goal != "" { if p, ok := prioMap[a.Goal]; ok { currentPrio = p + values.Priority(a.Cfg.Stickiness) } }
    topPrio := priorities[0].Priority; topDim := priorities[0].Dim
    if a.Goal == ""     { a.Goal = topDim; return true }
    if a.Goal == topDim { return false }
    if float64(topPrio) - float64(currentPrio) > a.Cfg.GoalDeadband { a.Goal = topDim; return true }
    return false
}

func (a *Agent) clearGoal() { a.Goal = ""; a.Plan = planner.Plan{}; a.PlanIdx = 0; a.Elapsed = 0 }
```

## 8. §F — Hostile/encroach perception → Safety-intensity rise + defensive Safety goal `(ACTIVATED)`

This is a core-tick concern (phase 1b). The threat scan RAISES the conditional `Safety` need
intensity via `needs.UpdateConditionalNeeds` (so the appraisal chain sees Safety pressure) AND fires
the forced-goal reflex.

**Config fields (this file owns them):** `ThreatTags []core.Tag` (balance.yaml
`threats.hostile_tags`), `SafetyDim core.Dimension` (content/needs.yaml Safety id),
`ThreatPerThreatGain float64` (balance.yaml `threats.per_threat_intensity`), `ThreatSafetyDecay
float64` (balance.yaml `threats.safety_decay`). All injected (D10); `Config.ThreatTags`/`SafetyDim`
MUST be populated by `main.go` (BLOCKER-2) — otherwise the phase is inert.

### `scanThreats()` — the threat-list producer

```go
// scanThreats scans perceived entities for any whose tags intersect Config.ThreatTags.
// Returns a deduplicated, AgentID-sorted list (D12 count-stability for UpdateConditionalNeeds).
// ONLY entities tagged "agent" are threats (matches the near_other test).
func (a *Agent) scanThreats(seen []perception.PerceivedEntity) []core.AgentID {
    if len(a.Cfg.ThreatTags) == 0 { return nil }
    seenSet := map[core.AgentID]struct{}{}
    for _, e := range seen {
        if !hasTag(e.Tags, "agent") { continue }              // only agents are threats
        if tagsIntersect(e.Tags, a.Cfg.ThreatTags) { seenSet[core.AgentID(e.ID)] = struct{}{} }
    }
    if len(seenSet) == 0 { return nil }
    result := keys(seenSet); sort.Slice(result, byAgentIDString)  // dedupe + AgentID-sorted (D12)
    return result
}
```

`hasTag(tags, "agent")` and `tagsIntersect(tags, needles)` are the membership helpers; the agent
tests membership against the injected `ThreatTags` set, never against a specific tag-name literal
(D7/D10).

### `driveConditionalSafety()` — the Safety-intensity driver (runs EVERY tick, threat or not)

```go
// driveConditionalSafety drives NeedIntensities[SafetyDim] from the threat list.
// Runs BEFORE phase-3 appraise. The rise/decay/clamp arithmetic lives in
// needs.Def.UpdateConditionalNeeds (pure); the agent only supplies the list + the two
// injected constants and stores the result (D5).
func (a *Agent) driveConditionalSafety(threats []core.AgentID, needsReg *needs.Registry) {
    if a.Cfg.SafetyDim == "" { return }
    def, ok := needsReg.Def(a.Cfg.SafetyDim); if !ok { return }
    cur := a.NeedIntensities[a.Cfg.SafetyDim]
    a.NeedIntensities[a.Cfg.SafetyDim] =
        def.UpdateConditionalNeeds(cur, threats, a.Cfg.ThreatPerThreatGain, a.Cfg.ThreatSafetyDecay)
}
```

- When `len(threats) ≥ 1` the intensity RISES by `ThreatPerThreatGain × len(threats)`, clamped to
  `[0,1]`. When `threats` is empty it DECAYS toward 0 by `ThreatSafetyDecay` per tick (reaching 0
  over `⌈cur/ThreatSafetyDecay⌉` ticks). The math is owned by `engine/needs` — see Out of Scope.

### Forced-goal reflex (pre-empts the mediated goal)

```go
goalForced := len(threats) > 0 && a.Cfg.SafetyDim != ""
if goalForced {
    a.Plan = planner.Plan{}                       // clear plan → needsReplan returns true → re-plan for Safety
    emit GoalSelected{dimension: cfg.SafetyDim, priority: 1.0, eff_value: 1.0}  // emitted immediately (phase 1b)
}
// … (phases 2,3,4 run) …
// Phase 4b: apply the override AFTER mediateGoal so it truly overrides:

```

The override forces the Safety **Dimension** only — the planner/values resolve how to satisfy it as
usual (D5). The reaction is the ordinary Safety-need pursuit; only the trigger is the perceived
content-authored threat tag (D2: no hardcoded fight/flight subsystem). The threat tag and `SafetyDim`
are both injected (no `"Safety"`/`"hostile"` literal in logic, D7/D10). Determinism: the scan
iterates perceived entities in ObjectID-sorted order, the threat list is deduped + AgentID-sorted,
the override is rng-free (D12).

> **Why phase 1b runs before appraise:** the conditional Safety intensity is STATE the appraisal
> chain reads; driving it after appraise would delay the Safety Priority by a tick and break the
> reflex.

## 9. Referent-aware Urgency wiring (P5)

The agent aggregates the **maximum Priority across ANY referent** (Self, Other, Place, Collective)
into the effective `combinedPriority` it injects (normalized) as `Urgency`:

```
combinedPriority = max( selfMax, maxOther, maxPlace, maxCollective )      // OWNED here
```

`combinedPriority` is **owned in phase 3 of this file** and **consumed by `SPEC-politics.md §H`**
(`emitVoteIfEligible` reads it) and by `replan` (normalized into the snapshot `Urgency`). When the
highest Priority across any referent exceeds `conscience_urgency_threshold`, the planner's
conscience-loosening fires (the planner reads `agent.Urgency`), so caring for an Other in distress, a
Place in degradation, or a Collective under threat can lower the effective conscience threshold.

### `appraiseOthers()` — Other-referent max priority

Iterates `a.ToM.Subjects()` (sorted, D12), skips self, skips Others with `Affinity <=
MinCareThreshold`; for each cared-for Other and each need Dimension, derives the referent input via
`values.DeriveReferentInput(Other, …)` → `ComputeStanding/Salience`, then applies the **per-agent
bond multiplier** `1 + Affinity·BondAffinityGain` to the base weight before `ComputePriority`. Returns
the max. The bond multiplication is the agent's job (values is referent-agnostic — see
`engine/values/SPEC.md` Out of Scope). The low-Intelligence mood proxy stat is resolved via
`resolveOtherMoodStatID(statsReg)` (first Disposition stat, D7 — no literal).

### `appraisePlace()` — Place-referent max priority (Scenario E)

Iterates `a.Values` with `Ref.Kind == core.Place`. For each, reads `world.PlaceQuality(ref.ID)`,
applies the posture mapping, then `DeriveReferentInput(Place, …)` → `ComputeStanding/Salience/Priority`:

- `Maximize` → `mappedQuality = placeQuality`.
- `MaintainAbove` / `PreventBelow` → `1.0` if `placeQuality >= Setpoint`, else
  `1.0 - clamp01((Setpoint - placeQuality)/Setpoint)`.

Returns the max across Place values (0 if none held).

### `appraiseCollective()` — Collective-referent max priority (Scenario G prerequisite)

Iterates `a.Values` with `Ref.Kind == core.Collective`. Gathers `world.MemberNeedIntensities()`
(returns nil → contributes 0); builds a `[]values.ReferentInput` over member intensities (iterating
`sortedAgentIDs(members)`, D12), then `DeriveReferentInput(Collective, …, members, …)` →
`ComputeStanding/Salience/Priority`. The aggregation mode (min/mean) lives in `engine/values`.
Returns the max across Collective values (0 if none held or no member data).

### `defensiveCollectiveGoal()` — phase-4b Collective defensive override (BLOCKER-2)

```go
// Returns (dim, true) when the agent holds a protective Collective value (MaintainAbove/
// PreventBelow) on a dimension whose mean collective satisfaction (1 − mean member
// need-intensity) has dropped below Cfg.SafetyThreatThreshold. First breached value wins.
// Agents holding no such value (random-spawn default) are never affected.
func (a *Agent) defensiveCollectiveGoal(world WorldView, needsReg *needs.Registry) (core.Dimension, bool) {
    if a.Cfg.SafetyThreatThreshold <= 0 || len(a.Values) == 0 { return "", false }
    members := world.MemberNeedIntensities(); if len(members) == 0 { return "", false }
    for _, val := range a.Values {                                    // held order (sorted, D12)
        if val.Ref.Kind != core.Collective { continue }
        if val.Posture != core.MaintainAbove && val.Posture != core.PreventBelow { continue }
        dim := val.Dimension; if _, ok := needsReg.Def(dim); !ok { continue }
        mean := mean over sortedAgentIDs(members) of members[aid][dim]
        if (1.0 - mean) < a.Cfg.SafetyThreatThreshold { return dim, true }
    }
    return "", false
}
```

The planner resolves the forced Safety goal to **Patrol** (`content/actions.yaml` Patrol
`produces: [public_safety, has_Safety]`, `requires: [at_target]`). Verified by
`TestScenarioG_DefensiveGoalSelectsPatrol`.

## 10. replan() — the planner call

```go
func (a *Agent) replan(world WorldView, now core.Tick, rng *rng.RNG, svc Services,
    priorities []planner.DimensionPriority, combinedPriority float64) (planner.Plan, planner.Trace, error)
```

Builds the planner `AgentSnapshot` and delegates to `svc.Planner.Plan`. Steps:

1. **Known set:** `knownObjs := world.KnownObjects(a.ID)` → `knownSet map[ObjectID]struct{}`.
2. **Self-belief:** `selfBelief, _ := a.ToM.Self(a.ToM.SelfID())` (ToM[self], D8).
3. **Urgency:** `urgency := clamp01(combinedPriority / a.Cfg.MaxPossiblePriority)`.
4. **SatisfiedFacts:** scan `world.EntitiesInRadius(a.Pos, interactionRadius)` (`interactionRadius =
   5.0`), skipping self; set `near_other` if any nearby `agent`, `owned_by_other` if that agent is
   also `has_items`; set `tradeOffered` if `world.HasPendingOffer(a.ID)`.
5. **Base budget (§A-budget — formula details in `SPEC-dynamics.md §A-budget`):**
   ```go
   perceivedIntel := a.normalizedIntelligence(svc.Stats)                       // [0,1], reads ToM[self] (D8)
   effectiveNodes := a.Cfg.BudgetBase + int(perceivedIntel*float64(a.Cfg.BudgetPerIntelligence))
   ```
6. **AgentSnapshot** (every field):
   ```go
   snapshot := planner.AgentSnapshot{
       ID:              core.ObjectID(a.ID),
       Pos:             a.Pos,
       CurrentStats:    a.RealStats,        // god view; planner decides OUTCOMES, not visible to decisions
       SelfModel:       selfBelief,         // ToM[self] (D8)
       NeedIntensities: a.NeedIntensities,
       Known:           knownSet,
       Urgency:         urgency,            // referent-aware (§9)
       SatisfiedFacts:  satisfiedFacts,
       Stamina:         a.Stamina,          // live body scalar (gate coupling, SPEC-dynamics §D)
       Mood:            a.Mood,             // live body scalar (apathy gate)
       Adrenaline:      a.Adrenaline,       // live body scalar (adrenaline-cost gate)
       // ApathyBudget set conditionally below.
   }
   ```
7. **Apathy budget computation (gap-closure fix — set ONLY under Apathy):**
   ```go
   if a.Coping == Apathy && a.Cfg.ApathyBudgetPenalty > 0 {
       factor := 1.0 - a.Cfg.ApathyBudgetPenalty
       reducedNodes   := max(int(float64(effectiveNodes)*factor),    1)
       reducedActions := max(int(float64(a.Cfg.BudgetBase)*factor),  1)
       reducedDepth   := max(int(float64(a.Cfg.BudgetBase/4)*factor),1)
       budget := planner.Budget{MaxNodes: reducedNodes, MaxActions: reducedActions, MaxDepth: reducedDepth}
       snapshot.ApathyBudget = &budget
   }
   // else: snapshot.ApathyBudget stays nil → planner uses its configured PlannerConfig.Budget unchanged.
   ```
   This is the **only** budget-override channel; the agent NEVER mutates the planner config (the
   planner is shared/immutable-after-New). The per-call `ApathyBudget` pointer scopes the override to
   one `Plan` call. See `SPEC-coping.md §A` for the cascade that puts the agent into `Apathy`, and
   `SPEC-dynamics.md §A-budget` for the budget formula rationale + the planner-side consumption
   contract (`engine/planner/SPEC.md AgentSnapshot.ApathyBudget`).
8. **Goal targeting:** `goalPriorities := promoteGoal(a.Goal, priorities)` moves `a.Goal` to index 0
   so the planner targets the mediated goal (fallback to original order if `a.Goal` not present).
9. `return svc.Planner.Plan(snapshot, goalPriorities, rng)`.

Determinism (D12): the snapshot is a pure function of (Agent state, world snapshot, Config); the
budget is rng-free; reducing the budget changes only the planner's search caps, not its ordering.

## 11. execute() — phase 6 skeleton

`func (a *Agent) execute(now core.Tick, actReg *actions.Registry, world WorldView) Intent` emits the
intent for the current durative step. If no plan or the plan is exhausted, returns
`Intent{Kind: IntentNone}`. Otherwise it binds the concrete target (`bindTarget` — nearest known
object of the action's `TargetKindID`, ties by ObjectID, D12), binds the locomotion **destination**
(`moveDestination` → `Intent.Move`), emits `IntentStart` on the first tick (`Elapsed == 0`) or
`IntentContinue` thereafter, advances `Elapsed += tickMinutes`, and calls `applyStaminaDelta`.

> **`moveDestination` (D3 parametric travel binding).** A *locomotion* action — one whose effect is a
> positional predicate, `isLocomotion(Produces)` = produces `at_target` or `near_other` — carries an
> absolute world destination in `Intent.Move`, which the world steps toward and ends on arrival
> (SPEC-tick §Movement). `MoveTo` (TargetLocation) heads to the **object the next object-targeted plan
> step operates on** (looked up via the same `bindTarget`, so MoveTo and its Forage/Drink/… consumer
> agree on the instance). `Approach` (TargetAgent, produces `near_other`) heads to the **nearest other
> agent** (`nearestAgentPos`, scanned within `approachScanRadius`; EntitiesInRadius is ObjectID-sorted
> so distance ties pick the lowest-ID agent, D12). Non-locomotion actions, or an unresolvable
> destination, leave `Intent.Move` at the agent's own position — a zero-length move that completes
> immediately and never freezes the agent.

> **The Stamina drain/regen logic** (`applyStaminaDelta`, `resolveEffortLevel`,
> `hasRestEffectPerMinute`, `resolveRegenRate` — data-driven effort levels + Rest/Sleep regen) is
> specified in **`SPEC-dynamics.md §D`**. This file owns only the intent-build scaffolding +
> `bindTarget` (parametric targeting, D3).

## 12. emitSignal() — phase 7 trade signals (Offer / Accept / Reject)

Owned by this core file. Produces an `IntentSignal` for the trade actions; all other actions
(including the Vote path, which is `SPEC-politics.md §H`) return `IntentNone` from here.

```go
func (a *Agent) emitSignal(now core.Tick, world WorldView) Intent {
    if len(a.Plan.Actions) == 0 || a.PlanIdx >= len(a.Plan.Actions) { return IntentNone }
    switch a.Plan.Actions[a.PlanIdx] {
    case "Offer":
        target := a.nearestOtherAgentID(world); if target == "" { return IntentNone }
        // ClaimedValue inflated inversely with perceived Honesty (D8: reads ToM[self]).
        // Lerps from the honest floor to the dishonest ceiling as perceived Honesty falls
        // (D10: band from balance.yaml trade.claim_inflate_{min,max}; no literal).
        honesty      := clamp01(a.perceivedStat("Honesty") / 100.0)
        claimedValue := a.Cfg.ClaimInflateMin + (1.0-honesty)*(a.Cfg.ClaimInflateMax-a.Cfg.ClaimInflateMin)
        truth        := honesty * claimedValue        // truth proportional to honesty (deception = |Claimed-Truth|)
        return Intent{Kind: IntentSignal, Agent: a.ID, Tick: now,
            Signal: &Signal{Kind: "Offer", Toward: target, Valence: 0.5,
                ClaimedValue: claimedValue, Truth: truth, Intensity: 0.7}}
    case "AcceptTrade":
        target := a.nearestOtherAgentID(world); if target == "" { return IntentNone }
        return Intent{Kind: IntentSignal, Agent: a.ID, Tick: now,
            Signal: &Signal{Kind: "Accept", Toward: target, Valence: 0.8, Intensity: 0.6}}
    case "RejectTrade":
        target := a.nearestOtherAgentID(world); if target == "" { return IntentNone }
        return Intent{Kind: IntentSignal, Agent: a.ID, Tick: now,
            Signal: &Signal{Kind: "Reject", Toward: target, Valence: -0.3, Intensity: 0.5}}
    }
    return IntentNone
}
```

`nearestOtherAgentID(world)` returns the nearest other `agent`-tagged entity within
`interactionRadius`, or `""`. `Truth` is HIDDEN from the receiver — only the emitter and god know it;
the receiver weighs the claim by its own `ToM[emitter].Trust`.

> The `"Honesty"` string here is a known content literal in the current trade code; the D7/D10 guard
> targets balance constants and the canonical Intelligence/Vindictiveness/Aggression/Safety/Rest ids.

## 13. ApplyOutcome()

```go
func (a *Agent) ApplyOutcome(outcome ActionOutcome, rng *rng.RNG, cfg Config, reg *stats.Registry, emit core.EventEmitter)
```

Runs in the world's serial, fixed-AgentID apply phase (D12), AFTER all Tick intents are collected.
Mutations, in order:

1. **Durative completion / interruption:** if `outcome.Completed || Status == Interrupted`, on
   `Interrupted` discard partial progress (`Elapsed = 0`, P1 policy), then `PlanIdx++`, `Elapsed = 0`,
   and `emitActionDone`.
2. **β self-calibration:** `a.foldEvidence(outcome)` folds the world-provided evidence into
   `ToM[self]` (D8). On `Invisible`/`Interrupted` NO evidence is folded (self-sealing — see
   `SPEC-coping.md`).
3. **Mood update:** `a.Mood += cfg.Lambda * (outcome.Actual - outcome.Expected)` (the actual-vs-
   expected drive; see `SPEC-dynamics.md §E`).
4. **Effect application:** for each `dim, delta` in `outcome.Effect`,
   `a.NeedIntensities[dim] = clamp(a.NeedIntensities[dim] - delta, 0, 1e9)` (deltas DECREASE
   intensity, i.e. satisfy the need).
5. **FailStreak reset + Apathy single-success recovery:** if `Status == Succeeded && Completed`,
   `a.FailStreak = 0`; and if `a.Coping == Apathy`, set `a.Coping = Idle`, `a.Mood +=
   cfg.ApathyRecoverMood`, and `emitCopingEntered(Idle)`. (The Apathy-recovery mechanism is
   cross-referenced in `SPEC-coping.md §A` — single completed success exits Apathy.)
6. **Completed goal → reset:** if `outcome.Completed && a.PlanIdx >= len(a.Plan.Actions)`,
   `a.clearGoal()`, `a.Coping = Idle`, `a.Adrenaline = 0`.

`FailStreak` increment is handled in the Tick coping path (`enterCopingCascade`), NOT here.

## 22. Notes (the "why")

- **Why the body scalars are injected, not gate-side state.** Gates are stateless; the live
  Stamina/Mood/Adrenaline/Urgency are this module's Body state, written into the per-tick snapshot.
- **Why the per-call `ApathyBudget` and not a planner-config mutation.** The planner is shared and
  immutable-after-New (safe across goroutines during plan); mutating its config per agent would race
  and break determinism. The per-call snapshot field scopes the override to one `Plan` call.
- **Why the Safety drive lives in phase 1b, before appraise.** The conditional Safety intensity is
  STATE the appraisal chain reads; driving it after appraise would delay the Safety Priority by a
  tick and break the reflex. Running the §F drive right after the sight scan guarantees phase-3
  appraise sees the fresh intensity the same tick.
- **Why the §F forced-goal assignment is applied in phase 4b (not 1b).** The `GoalSelected` event +
  plan-clear happen in phase 1b for the trace, but the actual `a.Goal = SafetyDim` is set AFTER
  `mediateGoal` so the reflex truly overrides the mediated goal rather than being re-mediated away.
- **The §F defensive goal is a reflex, not a system (D2).** The hostile/encroach scan forces the
  Safety **Dimension** and drives the Safety **intensity** — the same Safety need the appraisal chain
  already arbitrates. The trigger (a content-authored threat tag) is data; the reaction (pursue
  Safety) is the ordinary planner pursuit. There is no hardcoded fight/flight subsystem.
- **Why `updateDynamics` uses self-only urgency.** The adrenaline surge is physiological and responds
  only to the agent's own deficit; the referent-aware `combinedPriority` is for the planner's
  conscience-loosening, not the body's panic response.
- **CopingEntered event mode strings (data-contracts §4).** Emit `mode` as the canonical string
  `rebind|longing|latent|apathy` (plus `idle` on recovery). Owned by SPEC-coping/SPEC-dynamics
  emitters but listed here for the loop trace.
- **Intelligence / Vindictiveness / Aggression / Mood / Safety / Rest / Function id resolution (D7).**
  All resolved from the registries / `Config` (`svc.Stats` for stats, `svc.Needs`/config for the
  Safety/Rest dimensions, `Config.Functions` for the goal→Function mapping), never a string literal
  in decision logic.
- **P4 gossip propagation is one-hop per tick.**
