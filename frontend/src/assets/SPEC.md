# SPEC — `frontend/src/assets`

> Status: `APPROVED` (plan: `docs/frontend-plan.md`, Q1/Q2/Q5 RESOLVED 2026-07-02)
> Layer: frontend leaf — no imports besides `src/types.ts`. Parent: [`frontend/SPEC.md`](../../SPEC.md).

## Purpose

The **data-driven asset registry**: everything that maps open-content simulation vocabulary
(species, ActionIDs, TerrainIDs — all extensible backend content, D10) onto render resources —
PNG spritesheets, poses, colours, FX timings. It is the D10 mirror on the render side: **adding a
species/action/terrain to backend content must never require a frontend code edit** — at worst a
manifest row + a PNG; at minimum nothing (the fallback chain draws a category glyph). Render
modules (`src/render/*`) consume these tables and the sprite cache; they contain **zero**
species/action/terrain conditionals.

## Asset file layout (`frontend/public/assets/`)

```
assets/
  fauna/<species>.png    one spritesheet per species: columns = animation frames,
                         rows = poses (which rows exist is declared in the manifest)
  flora/<species>.png    one sheet per plant species: single row, columns = growth stages
```
- Frame size is per-sheet (`frameW`×`frameH`, placeholder default 32×32); sheets are dense grids,
  no padding. Sprites face **+x (east)** at heading 0 so `rotate(heading)` orients them.
- Terrain has **no** asset files — flat per-cell colours from `TERRAIN_STYLE` (Q5).
- Placeholder sheets are generated by `frontend/dev/generate-spritesheets.mjs`
  ([`frontend/dev/SPEC.md`](../../dev/SPEC.md)) — deterministic bytes, so real art can replace a
  file without touching the manifest. The old prototype `assets/animals/*.svg` are superseded
  (removed when FE-P2 lands).

## Public Interface (`manifest.ts` + `sprites.ts`)

```ts
// ── manifest.ts — pure data + pure lookups ──────────────────────────────────
export type Pose = 'idle' | 'walk' | 'run' | 'eat' | 'attack' | 'dying'  // closed set (Q2)

export interface PoseClip { row: number; frames: number; fps: number }
export interface SheetDef {
  url: string                       // '/assets/fauna/deer.png'
  frameW: number; frameH: number
  poses: Partial<Record<Pose, PoseClip>>  // only rows the sheet actually has
}
export interface SpeciesStyle {
  sheet?: SheetDef                  // absent ⇒ glyph-only species
  category: 'predator' | 'prey'     // drives the fallback glyph shape/tint
  glyphColor: string
}
export const FAUNA_SHEETS: Record<string, SpeciesStyle>   // keyed by species id
export const DEFAULT_FAUNA: Record<'predator' | 'prey', SpeciesStyle> // glyph-only fallbacks

export interface FloraSheetDef { url: string; frameW: number; frameH: number; stageFrames: number }
export const FLORA_SHEETS: Record<string, FloraSheetDef>  // frame index = min(stage, stageFrames-1)
export const DEFAULT_FLORA_COLOR: string                  // glyph fallback (circle, stage-scaled)
export interface FloraCoverageStyle { color: string; radiusUnits: number; alpha: number }
export const FLORA_COVERAGE: Record<string, FloraCoverageStyle>  // ground-cover species (grass) →
  // density coverage wash instead of a sprite/dot; render branches on this style, not the species id

// Ordered first-match-wins ActionID→Pose rules (Q2). Patterns test the raw ActionID string.
export const ACTION_POSE_RULES: ReadonlyArray<{ pattern: RegExp; pose: Pose }>
export function poseFor(actionId: string): Pose            // first match, else 'idle'

export const TERRAIN_STYLE: Record<string, string>         // TerrainID → css colour
export const TERRAIN_DEFAULT: string                       // unknown TerrainID
export const WEAR_TRAIL_COLOR: string                      // wear overlay tint (alpha ∝ wear)

export interface FxDef { durationMs: number }
export const FX_DEFS: Record<'spawn' | 'death' | 'attack' | 'grow', FxDef>
// defaults: spawn 500, death 1500 (fade + corpse mark), attack 300 (lunge), grow 500 (Q4)

// ── sprites.ts — injected loader/cache (never a module-level singleton) ─────
export interface LoadedSheet { image: HTMLImageElement; def: SheetDef | FloraSheetDef; ready: boolean }
export interface SpriteCache {
  fauna(species: string): LoadedSheet | null   // null ⇒ caller uses the glyph fallback
  flora(species: string): LoadedSheet | null
  preload(): Promise<void>                     // kick all manifest urls; resolves when settled
}
export function createSpriteCache(doc?: Document): SpriteCache  // built in App, passed down as prop

// Pure frame picker: which source rect to draw at clockMs (loops at clip.fps).
export function frameRect(def: SheetDef, pose: Pose, clockMs: number):
  { sx: number; sy: number; sw: number; sh: number } | null   // null ⇒ pose row absent
```

## Fallback chain (must never throw, must always draw *something*)

1. `FAUNA_SHEETS[species]` absent → `DEFAULT_FAUNA[category?]`; with no category knowable,
   `prey` glyph. (Category for unknown species defaults to `prey`.)
2. Sheet declared but image not `ready` (still loading / 404) → category glyph.
3. `frameRect` pose row absent → try `walk`, then `idle`, then glyph.
4. Unknown TerrainID → `TERRAIN_DEFAULT`; unknown flora species → `DEFAULT_FLORA_COLOR` circle.

## Invariants

- **Data, not code (D10 mirror).** All species/action/terrain differentiation lives in the exported
  tables. A grep guard: no `render/` module and neither file here contains a species or ActionID
  string conditional (`=== 'wolf'`-style) outside the manifest literals.
- **Closed poses, open actions (Q2).** `Pose` is exactly the six literals; `poseFor` maps any
  string (unknown → `'idle'`) and never throws.
- **No module-level mutable state.** `sprites.ts` exports a factory; the cache instance is created
  in `App` and injected. `manifest.ts` exports frozen (`as const`/readonly) data only.
- **Pure frame selection.** `frameRect(def, pose, clockMs)` is a pure function of its arguments —
  the animation clock is the caller's `clockMs`, never `Date.now()` inside.
- **Fallback totality.** Every lookup path terminates in a drawable glyph/colour; missing assets
  degrade visually, never crash and never draw nothing-at-all for a live entity.
- **URL discipline.** Asset urls are root-relative `'/assets/...'` (Vite `public/` contract); the
  manifest never imports image modules (Q1: sheets live in `public/`, not `src/`).

## Acceptance Criteria (Vitest)

- [ ] **poseFor table** — `'hunt_deer'→attack`, `'attack'→attack`, `'flee'→run`, `'graze'→eat`,
  `'drink'→eat`, `'move_to'→walk`, `'wander'→walk`, `'sleep'→idle`, `'???unknown'→idle`.
- [ ] **frameRect cycles** — a clip `{row:1, frames:4, fps:8}` at `clockMs=0/125/500` returns
  frames 0/1/0 (loops); `sy = row*frameH`; absent pose returns `null`.
- [ ] **Fallback chain** — `fauna('unknown_beast')` yields `null` from the cache and the manifest
  resolves a `prey` glyph style; a sheet with only `walk` serves `frameRect(_, 'attack')→null` and
  the documented fallback order lands on `walk`.
- [ ] **Terrain style totality** — every TerrainID in `content/terrain.yaml` examples
  (`plain/water/steep/forest/swamp`) has a colour; an unknown id returns `TERRAIN_DEFAULT`.
- [ ] **No singleton** — importing `sprites.ts` twice creates no shared mutable state (factory
  returns independent caches); grep guard for top-level `new Image(`.
- [ ] **Manifest frozen** — mutating an exported table at runtime throws in strict mode
  (`Object.freeze` verified on `FAUNA_SHEETS`, `ACTION_POSE_RULES`, `TERRAIN_STYLE`, `FX_DEFS`).
