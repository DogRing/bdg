# PRD — 중세 마을 시뮬레이터

> 최상위 요구사항. *왜* 이렇게 설계했는지는 `docs/core/design.md`, *어떤 이름*인지는 `docs/core/glossary.md`.

## 1. 비전
신의 관점에서 마을 사람들이 자유롭게 사는 모습을 관찰하는 **에이전트 기반 시뮬레이션**.
사람의 행동은 사실상 무한히 자유롭다 — 만남·거래·사냥·채집·범죄·정치·건축. "대화"는 자연어가 아니라 의도·의지의 교환.
**LLM·신경망 미사용.** 모든 행동·사회현상은 수치 상호작용에서 *창발*한다.

## 2. 시스템 형태
- **백엔드(Go)**: 결정론적 시뮬레이션 코어(헤드리스).
- **Redis**: 라이브 상태 저장.
- **Postgres**: 주기적 백업(리플레이·분석).
- **SSE → frontend(향후)**: 그래픽만. 백엔드가 이벤트를 흘려보냄.
- 능력치·행동·게이트는 **`content/` 데이터로 추가·수정**(코어 무수정).

## 3. 기능 요구사항 (요약)
완전판은 `docs/core/design.md` §FR. 핵심:
- **FR-가치**: 에이전트는 아는 객체마다 주관 가치를 매기고(항상 가치 × 순간 현저성), 가장 값진 목표를 띄운다. 모르는 객체는 없다.
- **FR-계획**: HTN(방법 분해) + GOAP(전제 후방 연쇄)로 깊은 경로를 조립. 행동은 durative + 중단 가능.
- **FR-게이트**: 방법의 보임·선호를 다중 게이트(능력·양심·체력·무기력·아드레날린·앎)가 정함.
- **FR-예측**: 장기 목표는 forward-simulation으로 미래 소모를 예측해 미리 보급. 지능이 예측 능력을 게이트.
- **FR-자기인식**: 모든 수치는 실제/자기/타인(관찰자별) 3중. 자기인식은 행위로 per-stat 보정.
- **FR-평판**: 관찰자별 믿음의 분포. 신뢰 가중 가십으로 전파, 파벌별 모순 가능.
- **FR-창발**: 범죄·정치·파벌·협력·제도(촌장)를 하드코딩하지 않고 가치 충돌/정렬의 부산물로 창발.
- **FR-관측**: 신의 관점에서 3중 괴리·가치·목표·플랜·관계/위임/평판 분포·why 추적을 본다.

## 4. 비기능 요구사항
- **결정론**: 같은 시드 → 같은 결과. 리플레이/디버깅(상세 `docs/core/testing.md`).
- **규모**: 30~200 에이전트 가속 tick.
- **확장성**: 가치·행동·게이트·수치를 `content/` 데이터로 추가, 코어 무수정.
- **관측가능성**: 모든 결정의 근거 추적.
- **분리**: 시뮬 코어는 IO/표현과 완전 분리(헤드리스 실행).
- **성능**: 지각·근접 쿼리는 공간 해시로 국소.

## 5. 데이터 흐름
```
[engine 시뮬]  --tick 스냅샷-->  [Redis 라이브]  --주기 백업-->  [Postgres]
      |                              |
      +------ 이벤트 스트림 ----------+----- SSE -----> [frontend 그래픽(향후)]
```
스키마는 `docs/core/data-contracts.md`가 단일 소스.

## 6. 범위 (단계)
구현 순서는 `docs/core/architecture.md`(leaf-first). 단계별 완료 기준:
- **P0 스캐폴드**: tick 루프·공간해시·시간·결정론 RNG·레지스트리 골격 → 빈 마을이 결정론적으로 돈다.
- **P1 최소 루프**: 자기 가치 → 목표 → 간단 플래너 → durative 원자 행동 ~6 → 배고프면 알아서 사냥·섭취.
- **P2 경제·다중·HTN·지각**: 거래·이동·지각 3종·방법 DAG → 두 명이 거래.
- **P3 게이트·코핑·체력** → 약한/착한/지친 에이전트가 다른 경로·코핑.
- **P4 ToM·신호·평판·가십** → 사기 후 신뢰 군집에 평판 전파.
- **P5 지능·forward-sim·가치 확장** → 긴 여행 보급·사랑발 범죄·조망 분쟁.
- **P6 창발 제도·정치** → 촌장이 스크립트 없이 창발.
- **P7 신 관점·스케일·튜닝·생애주기** → 200명 안정 + 창발 지표 충족.

## 7. 성공 기준 (창발 지표)
충분히 돌렸을 때 *저절로* 나타나야 한다: 파벌별 모순 평판, 신뢰 무역망, 빈곤→범죄→응징, 사랑발 자기희생/범죄, 조망 분쟁, 위임 수렴 촌장, 협력 건축, 허세/소심(real/self 괴리), 지능별 예측-보급 분화. (튜닝 타깃은 `docs/core/testing.md`.)

## 8. 비-목표
LLM 런타임 사용, 자연어 대화 생성, 손으로 짠 퀘스트·제도·법, 개별 스킬, (초기) 사실적 3D·물리.
