## 영역별 추가거리

### 🌿 식물 (flora) — 지금: 성장·산출·전파·고사·그늘
- **재배/작물화** — 돌보면 산출↑ → 농사 창발(D2). `Plant`+provisioning.
- **토양 비옥도/고갈** — 수확이 토양 고갈, **부패 산물(거름)로 회복** → 휴경·윤작 (decay→flora 연결).
- **계절성** — 개화·결실·휴면이 철 따라 → 식량 부족 주기 (계절 의존).
- **재료 역할 분화** — 섬유(실/binding), 약초/독초, 땔감, 목재 등급 → 물질사슬 입력 다양화.
- **경쟁/천이** — 빛·물·자리 다툼, 풀→덤불→숲.
- 잔: 성장단계별 산출차, 동물 매개 씨앗(↔fauna).

### 🌦 날씨/온도 (climate) — 지금: 비→습도, 기온=f(시각,비), 낮/밤. parked: 계절·바람·해
- 🪨 **계절** — 최대 추가 (위 게이팅 1).
- **극단 기상** — 폭풍·가뭄·한파·홍수 → 위험 대응 창발 (가뭄→W2, 홍수→강 범람).
- **바람** — 불 번짐·씨앗 전파·체감온도.
- **눈/서리** — 적설 navcost·자원 은폐, 서리 고사, 강 결빙.
- **미기후** — 그늘·물가 시원, 고도/경사 기온차.
- 인터페이스: 몸(Agent)이 쓸 **체감온도/한기** 출력 미리 노출.

### 🦌 동물 (fauna) — 미설계 (물질사슬 다음)
- 🪨 **AI 모델** (위 게이팅 2).
- **생태 역할** — 사냥감(이동 식량·가죽), **포식자=움직이는 위협**(Safety 창발), 가축화 가능(D2), 청소부(사체·부패).
- **먹이사슬/개체군** — 남획→붕괴→포식자 아사 (↔공유지 L).
- **산물→물질사슬** — 고기(식량·부패 W10), 가죽, **뼈(craft 입력)**, **힘줄(binding W8)**, 젖/털.
- 잔: 무리/세력권, 계절 이주(↔계절), 작물/구조물 피해.

### 🗺 월드 생성기 (world-gen) — 미설계 (기반)
- 🪨 **생성 방식 + hydrology** (위 게이팅 3). 결정성 D12.
- **파이프라인(권장 물 중심)**: 고도(노이즈)→경사→물 흐름(강 깎임·호수·바다)→물근접=습도→base material→속성벡터→biome→자원 분포(광맥=산, 점토=물가, 식물=suitability).
- **초기 배치** — agent 수·위치·**초기 value/위협 시딩** (↔live-emergence-underseeded).
- 부트스트랩: 시나리오는 손으로 짠 테스트 월드 사용 → world-gen은 메커니즘 뒤에 와도 됨.

### 🏞 강/물 (rivers/water) — 지금: river=base material, 물=속성 (world-gen+climate에 흡수 or 독립 Tier2)
- **흐름(유향·유속)** — 高→低. 도하 난이도(W1)·운반·침식.
- **수위 변동/범람** — 비→상승, 가뭄→마름(W2). 도하 가능/불가 동적(W1).
- **깊이별 도하 + 다리** — 여울 vs 깊은 곳, 다리=물 위 구조물.
- **식수/관개/우물** — 물=소비재(몸 단계) + 작물 물대기(↔flora).
- **수계 자원** — 물고기(↔fauna), 갈대(↔flora), 염도(바다 식수불가·소금).
- **결빙** — 한파→얼음→통행 가능(↔겨울).

## 교차 연결 (한 곳을 바꾸면 같이 움직임)
- **decay → flora**: 부패 산물(거름) = 토양 비옥도 회복.
- **fauna → 물질사슬**: 뼈·힘줄·가죽 = 이미 있는 craft 입력(W7/W8) 공급원.
- **계절 → 전부**: 식량주기·저온저장(W9)·이주·겨울 생존·파종.
- **world-gen(강/biome) → terrain·flora 배치**: 생성이 분포를 좌우.
